# Sotelo-Digital

> Tu web a medida, lista para vender. Diseño web de alta conversión y soporte técnico continuo.

## 🚀 Tecnologías
- **Vite**
- **TypeScript**
- **HTML5 semántico & Vanilla CSS**
- **Lucide Icons**

## 📦 Instalación y Uso

```bash
# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
